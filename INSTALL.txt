RecordsNext 3.1.0
INSTALLAZIONE E PRIMO AVVIO
===========================

RecordsNext by mauz79

1. REQUISITI
============
- Windows
- Java 21 o superiore
- Fantacalcio Manager
- file FCM/FCA della lega

UCanAccess 2.0.9.5 e le dipendenze necessarie sono inclusi nel pacchetto FULL.

2. PRIMA INSTALLAZIONE
======================
1. Estrarre completamente RecordsNext_3.1.0_FULL.zip.
2. Eseguire INSTALLA_RECORDSNEXT.bat.
3. Indicare la cartella di installazione, ad esempio:
   <cartella FCM>\plugin\RecordsNext
4. L'installer verifica Java 21+, runtime e integrita minima del payload.

L'installer NON installa database personali, NON copia FCM/FCA e NON pubblica file nei siti FCM.

3. AVVIO
========
Eseguire RecordsNext.bat.

4. CONFIGURAZIONE STAGIONI
==========================
Per una stagione GESTITA:
- FCM obbligatorio;
- FCA obbligatorio;
- sito locale opzionale;
- sito online opzionale.

La cartella js deriva da <cartella sito>\js.
Una stagione senza sito resta comunque parte dello storico.

5. DATAA
========
Il DataA canonico e':
data\calendars\DataA-YYYY.js

Esempio:
2025_2026 -> data\calendars\DataA-2025.js

6. PUBBLICAZIONE
================
Uso normale:
- Consolidata;
- Elabora;
- "Pubblica nel sito della stagione corrente al termine".

Riallineamento storico:
- selezionare le stagioni interessate;
- usare "Pubblica i siti delle stagioni selezionate".

Ogni sito riceve soltanto lo storico fino alla propria stagione.

7. OUTPUT
=========
fcmRecordsNext_Core.js
fcmRecordsNext_Manifest.js
fcmRecordsNext_Classics.js
fcmRecordsNext_Series.js
fcmRecordsNext_RU.js
fcmRecordsNext_Modifiers.js
fcmRecordsNext_ThresholdsLuck.js
fcmRecordsNext_Culometro.js
fcmRecordsNext_Matches.js

8. AGGIORNAMENTO
================
Usare RecordsNext_3.1.0_UPDATE.zip ed eseguire Aggiorna-RecordsNext-3.1.bat.
L'updater crea un backup e conserva config e data.
